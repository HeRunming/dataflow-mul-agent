Return complete Python source and data fixtures only after proving no existing candidate can express the step. Use OperatorABC from dataflow.core and @OPERATOR_REGISTRY.register() from dataflow.utils.registry. Implement get_desc and run(self, storage: DataFlowStorage, input_key: str, output_key: str = ..., **explicit_field_params) using storage.read('dataframe'), transformation, storage.write(df), and a returned list of written field names. The source must parse as a module and contain exactly one registered OperatorABC class with a run method. Constructor parameters must be JSON literals or explicit {$resource: name} dependencies. No external I/O, shell, eval or dependency installation. Each fixture contains input and expected lists of complete rows using actual run_args field names. Include a boundary case. Inputs: step, rejected candidates, allow_custom. Output: name, source, reason, tests and binding. Tools: controller materialization and pipeline.compile_and_run. Failure returns an explanation, never a stub. Controller stores source under the run custom directory and imports it only after review. Registration is process-local, never an upstream edit. Verified source and fixtures become reusable assets.
